O que é Git e GitHub

Git

o git e um sistema de controle de versões que permite acompanhar as alterações realizadas nos arquivos de um projeto

Com ele podemos registrar alterações, recuperar versões anteriores e trabalhar em equipe

GitHub

O git hub é uma plataforma online que permite armazenar e compartilhar repositórios git

por meio dele, podemos ompartilhar projetos, colaborar com outros desenvolvedores e visualizar o histórico de atualizações
